# BiliEnhancer · B站增强扩展

> 把 B 站官方默认不给你的体验，一个个拿回来。

一个轻量的浏览器扩展，为 B 站网页端补齐四项官方没有直接提供的功能：**评论 IP 属地显示**、**分P标题变真链接**、**移除直播间遮罩**、**更多倍速档位**。

------

## ✨ 功能

| 功能                       | 页面                      | 说明                                                         |
| :------------------------- | :------------------------ | :----------------------------------------------------------- |
| **评论 IP 属地**           | 视频 / 列表 / 动态 / 课程 | 在新版评论区每条评论的发布时间旁显示，如 `2025-02-03 15:39 河南`；按时间排序时若接口返回楼层号，一并显示 `#楼层`，B站已经不提供该数据，不会显示 |
| **分P标题`<div>`变 `<a>`** | 视频 / 列表               | 把分P列表的`<div>`标题包裹成真正的链接，支持右键「复制链接地址」、中键「在新标签页打开」、Ctrl+左键新开，优化体验 |
| **移除直播间遮罩**         | 直播间                    | 移除 `web-player-module-area-mask-panel` 遮罩，SPA 切换直播间后自动重新检测 |
| **更多倍速**               | 视频                      | 在官方倍速菜单之外增加 `1.8x`、`2.5x`、`3.0x` 档位           |

## 📦 安装

### 从源码加载（开发版）

1. 下载或克隆本仓库到本地。
2. 打开 Chrome / Edge，访问 `chrome://extensions/` 或 `edge://extensions/`。
3. 开启右上角 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择仓库根目录。
5. 打开 B 站任意视频页，刷新即可生效。

> **浏览器要求**：Chrome 111+（`content_scripts` 的 `"world": "MAIN"` 从 111 开始支持）。Edge 对该字段支持较晚，若加载报错，请升级到最新版 Edge。

## 🔍 各功能原理与限制

### 评论 IP 属地（`ip-reveal.js`）

**原理**
B 站新版评论区是 Lit Web Components（`<bili-comment-renderer>`）。脚本在 `document_start` 阶段 Hook `customElements.define`，在 `bili-comment-renderer` 注册时包装它的 `connectedCallback` 和 `attributeChangedCallback`，从组件实例的 `__data.reply_control.location` 读出 IP 属地，注入到 Shadow DOM 的 `#pubdate` 后面或 `#tags` 容器里。

**限制**

- 仅对 **2022-07-25 11:00 之后** 发布的评论有效，更早的历史评论接口本身就不返回 `location`。
- **置顶评论、UP 主本人评论**可能不带 `location`，此时不显示 IP 标签，属正常现象。
- **楼层号 `#N`** 只在按时间排序的评论列表里返回；热门排序（`mode=3`）不返回 `floor`，此时只显示 IP 属地。
- 仅覆盖新版 Shadow DOM 评论区；番剧页、空间页等旧版 `bbComment` 架构不在范围内。

### 分P标题变 `<a>`（`pod-link.js`）

**原理**
从 `window.__INITIAL_STATE__.videoData.pages` 读取 `cid → page` 映射，用每个 `.video-pod__item` 上的 `data-key`（即 cid）反查页码，拼出 `?p=N`，再把 `.title-txt` 的原有子节点整体搬进一个 `<a>`。左键点击 `preventDefault()` 交给 B 站 SPA，右键/中键保留原生链接行为。

**限制**

- 依赖 `__INITIAL_STATE__`。B 站 SPA 切换视频时该对象不一定重写，切换到另一个多P视频后 `cidMap` 可能仍是旧数据；代码有 `idx + 1` 兜底，但分P顺序与 DOM 顺序不一致时可能跳错 P。
- 包裹后 Vue 重渲染可能拆掉 `<a>` 层级，MutationObserver 会在下一帧重新包裹，偶尔会有闪烁。
- 仅在 `.video-pod__list` 存在的页面生效（视频页、列表页），动态页、课程页不会触发。

### 移除直播间遮罩（`remove-mask.js`）

**原理**
`setInterval` 每 500ms 查一次 `#web-player-module-area-mask-panel`，找到就 `remove()`，最多尝试 20 次（约 10 秒）。成功后停表；另有一个 1 秒轮询检测 `location.href` 变化，SPA 切换直播间后重置状态、重新开始一轮检测。

**限制**

- 只在 `live.bilibili.com` 生效，不影响主站视频页。
- 如果 B 站更换遮罩元素的 id，需要同步更新脚本里的 `TARGET_ID`。

### 更多倍速（`speed.js`）

**原理**
在 `<video>` 元素上直接设置 `playbackRate`，并在官方倍速菜单里插入 `1.8x`、`2.5x`、`3.0x` 选项。

**限制**

- B 站播放器会对倍速做范围校验，极端倍速（如 > 4x）可能被播放器重置回 2x。
- 倍速在切 P、切清晰度后可能被重置，脚本会重新应用。

## ❓ 常见问题

**Q：评论区的 IP 属地不显示？**
按顺序检查：

1. 该评论是否发布于 2022-07-25 之后（更早的评论没有数据）；
2. 是否是置顶评论 / UP 主本人评论（这类评论可能不下发 `location`）；
3. 扩展是否已启用、页面是否已刷新；
4. 打开 DevTools 控制台看是否有报错。

**Q：楼层号 `#N` 不显示？**
正常。楼层号只在按时间排序的评论接口里返回，B 站不下发 `floor`，脚本会自动跳过。

**Q：分P标题变成链接后，左键点击没反应？**
脚本对左键普通点击做了 `preventDefault()`，把控制权交回 B 站 SPA。如果你想左键也整页跳转，可以修改 `pod-link.js`，删掉 `a.addEventListener('click', ...)` 那段。

**Q：直播间遮罩移除了，切到另一个直播间又出现了？**
脚本会在 `location.href` 变化后重新检测，通常 1–2 秒内会再次移除。如果持续出现，可能是 B 站更换了遮罩 id，需要更新 `TARGET_ID`。

## 🔒 隐私声明

- 本扩展**不收集、不上传、不存储**任何用户数据。
- 所有逻辑在浏览器本地执行，不发起任何额外网络请求。
- 不读取 Cookie、不读取登录凭证、不修改账号状态。
- 显示的是 B 站接口已经返回、但网页端未渲染的字段，不涉及任何“破解”或越权访问。

## 🛠️ 开发

修改任意 `scripts/*.js` 后，在 `chrome://extensions/` 点击该扩展的 **刷新** 按钮，再刷新 B 站页面即可生效。

调试建议：

- **隔离世界脚本**（`remove-mask.js`、`multiple-speeds.js`）：DevTools 控制台直接看日志。
- **主世界脚本**（`ip-reveal.js`、`pod-link.js`）：在控制台左上角把执行上下文从 `top` 切到页面本身（通常显示为域名），才能访问脚本里的 `window` 变量。
